# EggyPartyCopyMapTextProcessor

蛋仔派对地图分享文本处理器

## 简介

当你从《蛋仔派对》游戏中复制地图分享文本（例如：`复制打开【蛋仔派对】，游玩地图《地图名》，地图码1234-5678。`）时，本程序可以自动解析其中的**地图名**和**地图码**，并生成格式化的标题与简介内容，方便用于视频标题、帖子发布或存档记录。

## 功能

- 自动提取地图名（`《》` 中的内容）
- 自动提取地图码（支持 `1234-5678` 格式）
- 生成预设格式的输出内容
- 将结果保存为 `.txt` 文件（文件名包含地图名，避免重复）
- 异常处理并记录错误日志

## 运行环境

- **框架**：.NET Framework 4.6.2
- **操作系统**：Windows 7 / 8 / 10 / 11
- **依赖**：无第三方库

## 使用方法

1. 在游戏中复制地图分享文本（点击地图介绍界面的地图码复制）
2. 运行本程序
3. 根据提示粘贴输入的文本并回车
4. 程序自动生成 `.txt` 文件到程序所在目录

### 输入示例

```
复制打开【蛋仔派对】，游玩地图《梦幻游乐园》，地图码5821-3497。
```

### 输出内容示例

```
【蛋仔派对】地图《梦幻游乐园》试玩

相关游戏：蛋仔派对
地图名：梦幻游乐园
地图码：5821-3497
(EggyPartyCopyMapTextProcessor Generate)
```

### 输出文件

- 文件名：`EggPartyMap_梦幻游乐园.txt`
- 位置：程序所在目录

## 错误处理

如果解析失败，程序会在控制台显示错误信息，并生成 `error_log.txt` 记录详细异常堆栈。

常见错误：
- 未找到地图名（缺少 `《》`）
- 未找到地图码（缺少地图码字段）

## 构建与编译

使用 Visual Studio 2019 或更高版本打开项目，选择目标框架为 `.NET Framework 4.6.2` 进行编译。

### 命令行编译（使用 MSBuild）

```bash
msbuild EggyPartyCopyMapTextProcessor.csproj /p:Configuration=Release /p:TargetFrameworkVersion=v4.6.2
```
